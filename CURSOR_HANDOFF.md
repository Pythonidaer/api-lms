# LMS integration handoff

This is a working static LMS generated by Design Lab. Keep learner markup and behavior from lms-runtime.js and use course.json as the course model. Sections can nest and contain slide decks, videos and multiple-choice quizzes. finalQuiz is separate. lms.css uses --lms-brand and --lms-radius; adapt those to shared website theme tokens. Course settings also store background/surface/text/muted/border colors, typography scale, spacing and content width. unlockAll defaults true; disabling it restores sequential/final requirements. Quiz skill labels support the completion-based skills report. Reports average each submitted quiz’s best score, omit time, and keep illustrative sample results separate from learner progress.

Test Learn, Reports, Settings, mobile outline, keyboard navigation, completion gates, retakes, captions/transcripts and browser persistence at 390/768/1440px. No video autoplays. Plain lesson text is escaped. Uploaded assets are local; external URLs stay external.

For shared reporting add users/enrollments, courses, lesson completions and quiz-attempt tables with an authenticated API. Grade on the server for trustworthy scores; never trust client completion/CSV. Add roles, access controls and a real instructor report before production multi-user use. Evaluate SCORM/xAPI only if needed by the target platform.
